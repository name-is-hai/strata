# Strata Notification

Notification is integrated as Strata's default notification service under the `strata.notifications` plugin ID. The panel, popups, actions, history, sound, and settings are managed by Strata. Existing Omapager history, quiet state, policy, icons, images, and reply data are copied once into Strata's state and config directories.

The imported service originated from [Omapager](https://github.com/njpatel/omapager). See [LICENSE](LICENSE) for its copyright and license.
