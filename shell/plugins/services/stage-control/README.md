# Strata Stage

Strata Stage adapts [Stage Control](https://github.com/marcho78/omarchy-stage-control)
by marcho78 under its MIT license. The original license is retained in
`LICENSE`.

Strata uses the existing three-finger window overview for quick switching.
Each three-finger direction is configurable in Strata Stage's Trackpad settings,
with the existing actions kept as defaults.
Stage owns four-finger vertical swipes: up opens the full window and desktop
stage, down opens the current app's windows. The existing four-finger horizontal
swipe remains Hyprland's native workspace gesture. The stage uses Strata's
accent, surface colors, font, wallpaper, menu, and lock command. Its settings
are stored on the `strata.stage-control` bar entry in Strata's `shell.json`.
