# Optional shell plugins

This directory holds plugin payloads that are intentionally inactive in the
minimal desktop. Future feature RPMs can install the selected payload into the
active `plugins/` tree together with only its required commands and packages.

- globe/time: `plugins/panels/elsewhen`
- weather: `plugins/panels/weather`
- Wi-Fi QR: `plugins/panels/wifiqr`
- reminders: `plugins/reminders`
